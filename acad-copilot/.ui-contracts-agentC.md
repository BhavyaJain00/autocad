# UI contracts used by the panel (agent C, 2026-11-19)

For agents A / B / D: what the panel already shows, so nobody wires it twice. Ask for changes in `.ui-requests-<you>.md`.

## Agent B (Core/Panel, Core/Agents)
- Settings > **AI BEHAVIOUR**: 4 check boxes bound to `ChatViewModel.AutoSwitchProvider / AskBeforeDrawing / AutoReview / TutorMode`,
  which read and write `(session as ICopilotAssist).Features` (`CopilotFeatures`). Other tabs refresh via `ChatViewModel.RefreshFeatures()`.
  `ProviderOrder` is shown (read-only) under "Switch AI when one stops".
- Every tab sets `ICopilotAssist.EmitNoticesAsText = false` (the panel renders the events itself):
  - `ProviderSwitched` -> `SwitchNoticeItem` (amber line, `Message`, tool tip `Detail`).
  - `ReviewCompleted` -> `ReviewCardItem` (reviewer, summary, Major/Minor rows, **Fix these**). Fix these shows "Fix these" as the
    user's message and sends `ReviewReport.FixPrompt`; while the tab works it goes into the tab's queue.
- The quick prompt "Review this plan" sends exactly `ChatViewModel.ReviewPrompt` = "Review this plan" (matches `ReviewRequests.IsReviewRequest`).
- Messages may contain `[point 12'-6",30'-0" (150,360)]` tokens (WCS, feet-inches then drawing units) and a block
  `[selected in AutoCAD: N objects in X.dwg (...)\n- HANDLE TYPE on LAYER, detail ...]`. A line about both in
  `CopilotInstructions` would help (tools: `pick_point`, `get_selection`, `select_objects`).

## Agent A (Recovery)
- `CopilotPaneOptions.ResumableJobs` (Func, UI thread) + `DismissJob`; `PaletteHost` wires them to
  `JobJournalStore.CreateDefault().FindUnfinished(new JournalDrawing(doc.Name, fileName, doc.IsNamedDrawing), otherSessionsOnly: true)`
  and `Dismiss(info.Session)`. Called once when the pane loads; call `CopilotPane.OfferResumableJobs()` again (e.g. on
  DocumentBecameCurrent) to offer jobs of another drawing. Cards: `ChatViewModel.ShowResumeOffer(ResumeInfo, Action<ResumeInfo>? dismissed)`.
- **Resume** sends "Resume the previous job that did not finish. Call get_resume_info first, check the drawing, then continue with what is left. " + `ResumeInfo.Summarize()`.

## Tools added by C (Plugin/Tools/ToolRegistry.Interaction.cs, Plugin/Interaction/)
- `pick_point` (Write: takes a turn, changes nothing), `get_selection` (Read), `select_objects` (Write: takes a turn, changes nothing).
